# Edgar Petrosyan: portfolio

Next.js 16 (App Router) + React 19 + TypeScript.

```bash
npm install
npm run dev        # http://localhost:3000
npm run build && npm start
```

Edit your content in `lib/data.ts`. The photo is `public/photo.jpg`.

## Deploy to Vercel (free Hobby plan)
Push this folder to GitHub, then Vercel → Add New → Project → pick the repo → Deploy.
Vercel detects Next.js automatically; no settings needed.
